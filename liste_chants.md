# Liste des chants

Les cases cochées indiquent les chants présents dans le dossier `songs/` de ce projet. Les artistes proviennent des fichiers de chants lorsqu’ils sont présents ; pour les autres, un interprète connu est indiqué. Pour les chants sans interprète unique, l’auteur, l’adaptateur ou la mention « traditionnel » est précisé. Les versions ambiguës sont signalées.
